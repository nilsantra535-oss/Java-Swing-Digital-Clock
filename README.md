# Java Swing Digital Clock ⏰

A simple, lightweight **Digital Clock** desktop application built in Java using **Swing** for the Graphical User Interface (GUI). It displays the real-time clock (hours, minutes, seconds, AM/PM), current day of the week, and formatted calendar date.

---

## Features ✨
- **Real-Time Updates:** Automatically updates the time every second using a background execution loop.
- **Modern UI Components:** Utilizes Java Swing (`JFrame`, `JPanel`, `JLabel`) with customized fonts (`SANS_SERIF`, `Ink Free`) and styling.
- **Complete Date & Time Info:** Displays:
  - Current Time (`hh:mm:ss a`)
  - Day of the Week (`EEEE`)
  - Calendar Date (`dd MMMMM, yyyy`)

---

## Prerequisites ☕
Make sure you have the following installed on your system:
- **Java Development Kit (JDK)** (Version 8 or higher recommended)
